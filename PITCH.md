# CommunityGlows — Pitch

> Pitch reviewed: 2026-09-02 · Project state: see canonical sources below

CommunityGlows is a unified social workspace for creators, operators, marketers, and small teams managing multiple channels. It aims to reduce context switching while preserving platform-specific behavior and local session boundaries across browser, desktop, web, and mobile surfaces.

## Current state

The shared Vue/Tauri codebase and Chrome, Firefox, Windows, Android, and web paths remain under active development; later platform support and in-development workflows are not dated availability promises.
