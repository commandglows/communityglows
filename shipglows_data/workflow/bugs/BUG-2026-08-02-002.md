# Bug Record: BUG-2026-08-02-002

## Summary

- Title: Windows native WebView obscures desktop settings
- Current status: `fix-attempted`
- Severity: `high`
- Owner: `106-sg-fix`
- Proof path: `evidence-first`; native child-window stacking cannot be reliably rendered by the Linux development host.

## Reproduction

- Preconditions: open any supported network in the Windows desktop installer.
- Steps:
  1. Click the header settings button.
  2. Observe the settings sheet.

## Expected Behavior

- The settings sheet is fully visible and interactive. Closing it restores the current network without recreating its warm native session.

## Observed Behavior

- The active native child WebView remains above the Vue settings sheet, hiding the settings UI.
