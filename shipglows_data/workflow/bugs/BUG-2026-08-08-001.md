# Bug Record: BUG-2026-08-08-001

## Summary

- Title: Windows profile creation controls close without opening the name field
- Current status: `fix-attempted`
- Severity: `medium`
- Owner: Diane

## Reproduction

- Preconditions:
  - Open the CommunityGlows dashboard on Windows/Tauri.
- Steps:
  1. Click `Ajouter un profil` in the right panel.
  2. Observe the profile creation field.
  3. Open the profile menu in the left panel and click `Add profile`.

## Expected Behavior

- Each action visibly opens the profile-name field and focuses it; entering a non-empty name creates and activates that profile.

## Observed Behavior

- The controls appear to do nothing.

## Evidence

- The right-panel control broadcast a global event that opened profile menus, but the originating click then reached each document-level outside-click listener and closed them in the same event propagation.
- The left profile-menu action did not stop propagation, leaving it vulnerable to the same outside-click close path.
