# Bug Record: BUG-2026-08-07-001

## Summary

- Title: Windows Get Started CTA does not reopen onboarding
- Current status: `fix-attempted`
- Severity: `medium`
- Owner: Diane

## Reproduction

- Preconditions:
  - Onboarding has already been completed.
  - The app displays the unauthenticated Windows dashboard/login view.
- Steps:
  1. Open the Windows/Tauri dashboard.
  2. Click `Get started`.
  3. Observe that the onboarding flow does not open.

## Expected Behavior

- `Get started` reopens the in-app onboarding flow from its first step.
- Email sign-in remains a separate action.

## Observed Behavior

- The CTA attempts an anonymous Convex sign-in and routes to Twitter only if that backend operation succeeds.
- When Convex is unavailable, the CTA leaves the user on the same screen.

## Evidence

- `LoginView.vue` wired `Get started` to `signIn('anonymous')`.
- Existing replay actions in desktop and mobile settings use `onboardingStore.reset()`.
