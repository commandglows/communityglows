# Bug Record: BUG-2026-08-08-003

## Summary

- Title: Windows password sign-in fails before the Convex session is confirmed
- Current status: `fix-attempted`
- Severity: `high`
- Owner: Diane
- Next command: `/sg-test --retest BUG-2026-08-08-003 on Windows package`

## Reproduction

- Preconditions:
  - Fresh signed-out Windows Tauri session with Convex configured.
- Steps:
  1. Open the account login screen.
  2. Submit valid email/password credentials.
  3. Observe the sync overlay flash and the app return to login.

## Expected Behavior

- Convex confirms the JWT on the realtime client, cloud data hydrates, then the authenticated app opens.

## Observed Behavior

- The Windows UI returns the generic account error and remains `signed_out` before any durable authenticated state is reached.

## Evidence

- Build `31317080341`, commit `d248e86`, `convex_configured: yes`, `online: yes`, `account_state: signed_out`.
- The configured Convex deployment accepted a public query and an auth-action contract request from the local environment; the backend is reachable.
- Resize events saturated the old fixed-size diagnostic list, hiding any auth events after a Windows login attempt.
