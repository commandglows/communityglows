# Bug Record: BUG-2026-08-08-002

## Summary

- Title: Windows installers can be published without the Convex runtime URL
- Current status: `fix-attempted`
- Severity: `high`
- Owner: Diane

## Reproduction

- Preconditions:
  - Build a Windows installer while the GitHub Actions secret `VITE_CONVEX_URL` is absent.
- Steps:
  1. Install and open the published Windows application.
  2. Select a sign-in action.

## Expected Behavior

- A published Windows installer includes the configured Convex deployment URL and can start account synchronization.

## Observed Behavior

- The application reports that account sync is unavailable because the build was not configured with a Convex backend.

## Evidence

- Vite statically replaces `VITE_*` environment variables during the production build; no runtime setting can restore a missing value in an installed binary.
- The manual and tagged Windows workflows passed `VITE_CONVEX_URL` to the build without first rejecting an empty value.
- Repository and organization secret inventories were checked without exposing secret values; `VITE_CONVEX_URL` was absent.
