## Reproduction

- Preconditions:
- Dépendance transitive `fast-uri@3.0.6` présente dans `pnpm-lock.yaml`
  - Dépendabot alertant CVE `2026-6321`
- Steps:
  1. Installer/résoudre les dépendances.
  2. Vérifier la version résolue de `fast-uri` dans le lockfile.

- Le projet doit utiliser une version patchée de `fast-uri` (>= `3.1.2`) pour ne pas exposer la faille de traversal/hôte.
